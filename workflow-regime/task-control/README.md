# 任务控制文档机制 — 体系总览

> 一套用**文档体系管理长期工程任务**的机制。回答：用什么文档、各自负责什么、怎么编写、怎么更新、生命周期如何。
> 与 goal 机制（见 `07_goal_mechanism.md`）配合：goal 提供"目标生命周期"，任务控制文档提供"目标的可观察记录载体"。

## 一、四类关键文档（常驻，其余均为临时）

| 文档 | 职责 | 生命周期 |
|------|------|---------|
| **主线任务文档**（`MAIN_TASKS.md`） | 当前主线 + 下一步 + 硬约束 | 常驻，随主线推进持续更新 |
| **搁置任务文档**（`PENDING_TASKS.md`） | 被阻塞/搁置但仍有价值的规划 | 常驻，随阻塞解除更新 |
| **交接文档**（`HANDOVER.md`） | 让下一 session 完整接续的状态快照 | 常驻，每 session 结束更新 |
| **工作日志文档**（`WORKLOG.md`） | 所有自主决策、质询、方案取舍、变化前后 | 常驻，持续追加 |

> **四类之外的一切任务控制文档都是临时文档**（`_` 前缀）：单个任务的工作簿、一次性审查、
> 过程记录。**确认完成或内容过少即删除归并**——完成总结并入 WORKLOG，临时文档不留存。
> 目标：不遗留、不污染文档体系。

## 二、文档分类（含临时）

| 文档 | 类型 | 职责 | 生命周期 |
|------|------|------|---------|
| `MAIN_TASKS.md` | 主线任务文档 | 当前最紧要 + 下一步 | 常驻，随主线更新 |
| `PENDING_TASKS.md` | 搁置任务文档 | 阻塞/搁置但有价值的规划 | 常驻，随阻塞解除更新 |
| `HANDOVER.md` | 交接文档 | 让下一 session 完整接续 | 常驻，每 session 结束更新 |
| `WORKLOG.md` | 工作日志文档 | 决策/质询/方案取舍/变化前后 | 常驻，持续追加 |
| `_<task>.md` | 临时任务文档 | 单个复杂任务的工作簿 | **临时**，完成后删除 |
| 决策记录 | 临时（并入主线/工作日志） | 重大方向决策依据 | 并入常驻文档，不独立留存 |

> 重大设计决策：**并入主线任务文档或工作日志**（决策记录段落），不设独立常驻文档——
> 保持文档体系最小化。

## 三、写作原则（对所有任务控制文档通用）

1. **单点真理**：同一事实只在一处维护。任务控制文档之间、与代码/技术文档之间不得复制同一事实的两份。
2. **只放指针与硬规则**：不复制其它文档内容；需要读者查事实时，指向权威源。
3. **以实跑为准，不冻结数字**：测试基线、计数以实际运行为准，不写死。
4. **"只记录，不断决"**：能自主决定的记录决定并推进；只有确实无法决定的才标记为"待决"。
5. **变化前后**：任何实现/测试/文档改动，记录"变化前后"供追溯。
6. **不写项目专属 token 进通用机制**：机制层描述用泛化表述。

## 四、文档间协作图

```
MAIN_TASKS（当前主线）── 推进 → WORKLOG（决策/变化沉淀）
      │                                │
      └── 阻塞/搁置 → PENDING_TASKS     │
      └── 复杂任务 → _<task>.md（临时）  │
      └── session 结束 → HANDOVER ──────┘
```

- **MAIN_TASKS**：现在在做什么、下一步、硬约束。主线每完成一项就更新。
- **PENDING_TASKS**：被阻塞/搁置但仍有价值的规划。阻塞解除后回 MAIN_TASKS。
- **WORKLOG**：所有决策与变化沉淀。任何自主决定都写这里。
- **HANDOVER**：session 边界的状态快照，让下一 session 完整接续。
- **临时任务文档**：单个复杂任务的工作簿，完成后删除（总结入 WORKLOG）。

## 五、文档治理纪律（关键）

- **设计阶段**：设计/决策先写**任务控制文档**（项目级任务控制目录或本机制），**不直接写进技术手册**。待实现落地后，按治理纪律择机收敛写入技术手册。
- **人类手册 vs 任务控制文档**：人类手册（`docs/`）只面向人类，**禁止智能体元信息**（工作流/过程/skill 引用/工具配置）；此类信息只存在于 `AGENTS.md` 与 skill 工作流层。
- **临时文档生命周期**：`_` 前缀，完成/交接后经确认**必须删除**，禁止长期留存。完成总结并入 WORKLOG。
- **删除纪律**：已完成条目从 MAIN_TASKS 移除；临时文档删除前确认状态已由 git 承载。
- **不留遗**：确认完成或内容过少的历史记录及时删除归并；目标是不遗留、不污染文档体系。
